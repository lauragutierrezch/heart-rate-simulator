# Heart Rate Simulator

A Python project that generates simulated heart-rate data and visualizes how it changes over time.

## Features

- Generates heart-rate values within a defined range
- Creates gradual changes between consecutive values
- Displays the data in a line graph
- Shows minimum and maximum heart-rate limits

## Requirements

- Python
- NumPy
- Matplotlib

Install the required libraries with:

```bash
pip install numpy matplotlib
```

## How to run

Download the project and run:

```bash
python heart_rate_sim.py
```

## Disclaimer

This project uses synthetic data for educational purposes. It is not a medical device and should not be used for medical diagnosis.
